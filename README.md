You can install this app via the ToonStore.
With this app you can install/start the new gui Freetoon.

Freetoon is replacing the Eneco Gui, it is fully written in C
and gives especially toon 1 devices a performance boost.
Memory usage is about 50% of the available memory on the Toon 1

Once Freetoon is started you can always switch back within Freetone via
Instellingen, tile UI-Modus

Existing functionality:
- same thermostat function as Eneco'gui
- buienradar
- agenda
- afvalophaaqldagen

  Via de Freetone Marketplace:
  - Sonos app inclusief Spotify support (native Sonos/Spotify API, no sonos-http-bridge needed)
  - Crypto prices
  - Temperaturelogger (same as the ToonStore app)

more to come.....
