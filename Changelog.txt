1.0.7
- Start/Install/Uninstall now check that ToonStore (TSC) really ran the Freetoon script: TSC deletes its command file after every command, so a press during another app's command (e.g. a PostNL login) was lost and nothing happened. The app now waits, shows "Wachten tot ToonStore (TSC) het script start...", offers the command again when it was dropped (never overwriting another app's pending command) and gives up after 3 minutes with a message, showing the buttons again
- "Bekijk log" shows only the current run after a press, so an old "launch initiated successfully" can no longer be mistaken for the current one
- command and action files are written to /var/volatile/tmp instead of /tmp (the /tmp symlink is broken on some Toons)

1.0.6
- new "Bekijk log" button: shows the install/switch log (and the launcher log) on the Toon itself, refreshed every 2 s while open
- freetoon.sh: switch log now kept on flash (/mnt/data/switch_to_freetoon.log, max ~100 KB) so it survives a reboot; /var/volatile/tmp/switch_to_freetoon.log is a link to it
- status texts point to the log button and are in Dutch

1.0.5
- freetoon.sh: all /etc/inittab edits now go through inittab_edit.sh (lock, validation, flash-safe write); script refuses to edit if no engine is available
- freetoon.sh: always uses the latest install.sh from GitHub instead of the bundled copy
- freetoon.sh: stock qt-gui row is now commented out intact (was wiped) and restored correctly on uninstall
- freetoon.sh: uninstall also removes marketplace integrations (inittab rows + /mnt/data/integrations)
